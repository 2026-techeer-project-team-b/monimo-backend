화면 캔버스상 배치(3행 그리드, 참고용): 1행 = WF-01~04, 2행 = WF-05~07 + WF-00(Shell), 3행 = WF-03b. 범례 프레임은 좌상단(0,0)에 별도 배치.

## 관찰: 빠진 것 / 개선 여지

- **URL Statistic, Error Analysis, OpenTelemetry Metric(Beta), Infrastructure, Users/Agent statistic, Help, User Personal Settings** 등 Pinpoint 원본 9개 화면 중 다수가 범례상 "제외"로 명시되어 있음(후순위/범위 밖/타 화면에 흡수). 즉 이 화면들은 계획적으로 빠진 것이며 우연한 누락이 아님.
- 범례 하단에 "제외한 우리 기능(핵심 5밖, 2차로)"로 **로그 검색 화면 · CSV 내보내기 · 계측 모듈 런타임 토글 · 전송 버퍼 설정 · 사용자 설정 탭 · 설치/파수꾼의 앱 선택**이 명시적으로 로드맵 밖으로 정리되어 있음.
- WF-06(설치 안내)과 WF-07(파수꾼 상태)에는 topbar의 앱 선택 드롭다운(`app-select`)이 없음 — 이는 위 "설치/파수꾼의 앱 선택 제외"와 일치하는 의도된 설계로 보임.
- 알람(WF-04) 채널 목록에 Slack·이메일·HTTPS 웹훅·PagerDuty 4종이 있으나, 알림 이력 표에는 Slack/이메일/PagerDuty만 등장하고 웹훅 사용 이력은 화면상 확인되지 않음(옵션만 존재, 실사용 예시 부족).
- WF-05(에이전트 관리)의 계측 모듈 체크리스트는 7종이 나열되어 있고 "런타임 토글 없음(ADR #25)"이 별도 텍스트로 명시되어 있어, 이는 조회 전용(읽기 표시)이고 변경 불가한 정보로 보임 — 값 변경 UI(체크박스처럼 보이지만 비활성)인지 실제 토글 가능한지는 스크린샷만으로는 상호작용 상태를 확정하기 어려움.
- WF-03b는 별도 메뉴 없이 WF-03에서만 진입 가능한 결과 화면인데, 뒤로가기(`‹인스펙터로`)는 있지만 브레드크럼이나 URL 상태 표시가 없어 딥링크/새로고침 시 진입 경로가 명확한지는 텍스트만으로 확인 불가.
- 페이지 제목(topbar `page-title`) 텍스트 레이어가 WF-00 Shell에서는 placeholder("페이지 제목")로 남아있고, 각 WF 화면의 실제 스크린샷에는 "서버맵", "서버맵 › 트랜잭션", "인스펙터", "알람", "에이전트", "설정", "파수꾼", "스레드 덤프" 등으로 구체화되어 있음 — 문서화(범례)에는 이 title 값들이 별도로 표로 정리되어 있지 않아 향후 화면 추가 시 참고 표가 없음.

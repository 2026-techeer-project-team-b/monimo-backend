# 모니모니터링 웹 화면 IA (v2 신규 디자인, 2026-09-21)

## 전역 프레임
- 데스크톱 1440×(가변) 단일 앱 셸: 좌측 사이드바(60/240px) + 상단바(서비스 선택 드롭다운 `GET /applications` · 시간 범위 · 자동 새로고침 · 사용자 메뉴 `GET /auth/me`) + 본문
- 사이드바 하단 **파수꾼 미니 카드**: 카나리 신선도(초 단위) — 정상/지연/끊김 3색. 클릭 → S10 플랫폼 상태
- 사이드바 메뉴 순서: 서버맵 · 트랜잭션 · 인스펙터 · 에러 · 로그 · 경보 · 설정 · 플랫폼 상태(파수꾼)

## 화면 목록

| ID | 화면 | 핵심기능 | 파일(artboard) | 주요 UI |
|---|---|---|---|---|
| S00 | 로그인 | (인증) | Login.dc.html | 이메일·비밀번호 폼, 오류 배너(401) |
| S01 | 서버맵 | ①트레이스 추적 | ServerMap.dc.html | React Flow형 노드-간선 그래프(호출량·에러·평균지연), 노드 클릭 사이드패널, 우측 미니 스캐터, 상단 발화 중 경보 띠 |
| S02 | 트랜잭션(스캐터·히트맵) | ④히트맵 | Transactions.dc.html | 스캐터(시각×응답시간, 성공/실패 색) ↔ 히트맵 토글, **드래그 선택 사각형** → 하단 요청 목록 표, URL 통계 탭 |
| S02b | 트랜잭션 — URL 통계 탭 활성 | ④히트맵 보조 | UrlStats.dc.html | 같은 화면, 하단 탭 URL 통계(span_name·cnt·err_cnt·error_rate·p50/p95/p99) |
| S03 | 트레이스 상세(콜스택) | ①트레이스 추적 | TraceDetail.dc.html | 서비스 경로 요약, 간트형 스팬 타임라인 트리(서비스별 색), 스팬 상세 패널(events·attributes), 연결 로그 탭 |
| S04 | 인스펙터(에이전트 메트릭) | ③시스템 메트릭 | Inspector.dc.html | 파드 목록 좌측, 파드 상세 헤더(호스트·JVM·상태), CPU·힙·GC·스레드 수 차트 4장, 지표 이름 드롭다운, **스레드 덤프 요청 버튼** |
| S04b | 인스펙터 — 스레드 덤프 요청 모달 | ③시스템 메트릭 | InspectorDumpModal.dc.html | timeout_ms 선택, 3단계 진행(접수→수집기 팬아웃→Extension 회수), 503 안내 |
| S05 | 스레드 덤프 | ③시스템 메트릭 | ThreadDump.dc.html | 덤프 목록 + 본문 뷰어(스레드 상태별 필터·검색), 요청 진행 모달(타임아웃·503 처리) |
| S06 | 에러 분석 | ①/② 보조 | Errors.dc.html | 시간대별 에러 건수 스택 차트(상태코드 대역·예외타입), 실패 스팬 표(→ 트레이스 상세) |
| S07 | 로그 검색 | 보조(FN-61) | Logs.dc.html | 필터 바(레벨·logger·trace_id·q), 결과 표(가상 스크롤), trace_id 링크 |
| S08 | 경보 — 이벤트 | ②알람 | Alerts.dc.html | 발화 중/해소 탭, 심각도 필터, 이벤트 표, 상세 드로어(규칙·파드·실측값·**알림 발송 이력**) |
| S08b | 경보 — 규칙 | ②알람·⑤config | AlertRules.dc.html | 규칙 표(켜기/끄기 토글), 규칙 생성/수정 모달(metric_kind 7종·operator·threshold·window·severity·채널 다중선택) |
| S08c | 경보 — 채널 | ②알람 | AlertChannels.dc.html | 채널 카드(SLACK/EMAIL/WEBHOOK/PAGERDUTY), 등록/수정 모달(type별 config 필드), **테스트 발송 버튼**과 결과, 켜기/끄기 |
| S09 | 설정 — 서비스·샘플링 | ⑤config UI | Settings.dc.html | 서비스 목록/등록/수정/삭제(409 안내), 선택 서비스의 **샘플링률 슬라이더 + 판번호(version) + 낙관적 잠금 충돌 안내**, 계정(내 정보·로그아웃) |
| S10 | 플랫폼 상태(파수꾼) | +파수꾼 | Watchdog.dc.html | 카나리 관통 경로 도식(파수꾼→쇼핑몰→에이전트→수집기→Kafka→CH→API 서버) 각 단계 신선도, 우리 서비스 6개 readyz 상태, 최근 카나리 경보 |

## 핵심기능 → 화면 매핑
| 핵심기능 | 완료 정의 | 화면 |
|---|---|---|
| ① Agent·트레이스 추적 | 여러 서비스를 거친 콜스택이 뜬다 | S01 서버맵 → S03 트레이스 상세 |
| ② 알람 | 5xx 비율 초과 시 사람에게 닿는다 | S08 이벤트 · S08b 규칙 · S08c 채널 |
| ③ 시스템 메트릭 | CPU·힙·GC + 스레드 덤프 | S04 인스펙터 · S05 스레드 덤프 |
| ④ 히트맵(스캐터) | 드래그로 긁으면 API 목록 | S02 트랜잭션 |
| ⑤ config UI | 재배포 없이 샘플링률·임계값 변경 | S09 설정(샘플링률) · S08b 규칙(임계값) |
| + 파수꾼 | 스택 다운 시 1분 내 알림 | S10 플랫폼 상태 + 사이드바 하단 파수꾼 미니 카드 |

## recent decisions (max 5)

- `#71` **`raw.dlq` 되넣기는 사람이 부르는 compose 잡 하나로 두고, 되넣기가 못 고치는 집계 구멍은 절차로 남긴다**(#195). `#96` 이 보내는 쪽까지만 만들어 30일 뒤엔 진짜 유실이었다. 같은 이미지 · 프로필 하나(`dlq-reprocess`) · 머리말 셋만 · 독성은 건너뛰고 `x-dlq-attempt` 3 에 닿으면 멈추고 커밋하지 않는다(lag 이 남아 점검이 말한다). **되넣기는 원본에 없는 것만 되살린다** : 집계 줄을 지우고 되넣었더니 `transactions` 가 0 에서 안 올라왔다(창이 블록을 버려 MV 가 안 돈다). 그래서 ADR #67 되돌림 ④ 의 사유를 고쳐 읽는다 : 기억 밖이 아니라 **기억 안에서도** 재집계가 필요하다. 경보는 포기한다(과거 버킷은 탐지가 무시한다)
- `#70` **롤업 `metrics_1m` · `metrics_1h` 에 꼬리표(`attributes`)를 `any` 로 남겨 원본이 지워진 뒤에도 갈래를 알 수 있게 한다**(#193). 꼬리표는 원본에만 있고 롤업엔 해시만 있어 원본 TTL 105일이 지나면 2027-01-05 부터 이름 없는 선이 될 거였다. 마이그레이션 하나 · 코드 0줄, 옛 줄은 안 채운다. 처음 `Map(LowCardinality…)` 로 썼다가 `any` 가 그것을 벗겨 `Code: 36` 이 나 `Map(String, String)` 으로 고쳤다
